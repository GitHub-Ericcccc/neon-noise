# NEON//NOISE

本项目派生自 [Arrow36/neon-noise](https://github.com/Arrow36/neon-noise)，保留并修改了上游实现，由 **GitHub-Ericcccc** 独立维护，不代表上游官方发布。显示参考 Spectroid，并非其官方版本或算法复刻。

## 本版本新增与调整

v1.1.0 将手机验收后的五模式录音界面作为正式首页，历史窗口扩展到60秒；原实验地址自动跳转首页。

- 紧凑深色布局、黄色当前频谱、红色峰值保持及共享频率坐标。
- 显示设置可分别调整曲线范围和蓝紫瀑布图色阶，颜色变化不改变测量值；输入增益仍实际改变分析输入。
- 红线默认按 4.5 dB/s 衰减，可选择保持至重置；“重置红线”单独清除保持值。
- 历史按快照时间戳排列，保留错过采集的间隙；调色或调整尺寸后从数值重绘，缓存单行颜色减少重复计算。
- 麦克风请求 15 秒未完成时退出等待，迟到的音频流会释放。
- 完整 MIT 文本内嵌于 HTML，单文件分发也携带许可。

当前未新增多 FFT、双指缩放或历史时刻选读。点击瀑布图仍只选择频率。


一个直接运行在浏览器中的实时噪音频谱分析仪，用于观察环境噪音、定位稳定频率峰值，并回看最近 60 秒的频谱变化。

## 在线使用

本 fork 在线部署地址为 [https://github-ericcccc.github.io/neon-noise/](https://github-ericcccc.github.io/neon-noise/)。[上游在线演示](https://arrow36.github.io/neon-noise/)展示上游版本。本地运行见下文。

首次使用时，请允许浏览器访问麦克风。建议使用最新版 Chrome 或 Edge；部分内置浏览器可能不会开放麦克风接口。

## 主要功能

- 32768 点 FFT 实时频谱分析
- 对数频率坐标与峰值保持
- 最近 60 秒的历史频谱瀑布图
- 平均功率、中位数、最大响声及噪声突出度分析
- 可点击、拖动或手动输入频率的自定义测量点
- 输入增益调节、开始与停止记录
- 针对手机和低性能设备降低绘制负载

## 本地运行

麦克风接口通常要求安全上下文。不要直接用 `file://` 打开文件，请在项目目录启动本地 HTTP 服务，例如：

```bash
node scripts/serve.cjs 8765
```

然后访问 <http://127.0.0.1:8765/>。这个服务只开放公开文件清单，不开放本地方案或录音。手机不能用此地址访问电脑；iPhone 请使用上面的正式 HTTPS 地址，并保持 Safari 前台。

## 使用方法

1. 点击“开始记录”并允许麦克风权限。
2. 在当前频谱中观察主要峰值，在历史频谱中查看它们是否持续出现。
3. 点击任一图表可创建测量点；拖动测量点可改变频率，再次点击标签可手动输入频率。
4. 点击“分析历史频谱”，从已有的最近 60 秒数据生成分析结果；不必等待满 60 秒。
5. 使用分析方式切换总体能量、稳定底噪、短促异响和持续噪声特征。

## 分析方式

- **平均功率频谱（总体能量）**：先在线性功率域求平均，适合观察一段时间内的总体声能。
- **中位数频谱（稳定底噪）**：降低偶发声音的影响，更适合寻找持续存在的背景噪音。
- **最大响声频谱（短促异响）**：保留每个频率在历史窗口内的最高值，突出短暂事件。
- **噪声频谱（噪声突出度＋出现率）**：综合频率相对周边的突出程度和历史出现频率，帮助寻找持续窄带噪音。
- **楼上噪声优化检测**：记录疑似低频撞击，不自动判定声源。

## 录音模式

统一界面默认选择楼上噪声优化检测。点击开始记录同步采集音频、检测事件及更新图表；停止记录保存最后音频分块并释放麦克风，保留画面和会话供分析、回听与导出。再次开始重置图表并创建新会话。五种分析共用记录功能；会话与导出位于当前频谱上方，统计位于 MIT 上方。

选择第五种模式，调整实验参数后点击“开始记录”。默认主频带 35～120 Hz、辅助 20～250 Hz，重点显示 50～75 Hz；学习背景 5 秒后计数。设置在会话期间锁定。独立短时检测使用显示增益之前的信号，切换其他分析不停止记录。单次最长 10 分钟，点击“停止记录”提前停止。

黄色低频曲线为滤波 RMS，青色为背景；事件列表显示候选次数、持续增强、滤波峰值和 RMS、背景增量与间隔。规律的至少四个候选事件可产生疑似步行序列及步频。所有电平是未经声压校准的 dBFS，不能从频谱认定体重、穿鞋情况或声源；高灵敏度允许误报。

结束后可定位播放完整录音，再生成并下载 ZIP，内含音频、CSV、JSON、HTML 报告、MIT 许可证与 SHA-256 清单。解压后打开报告；请人工核对完整音频、时间及文件内容，再点击确认已保存，才允许删除本地会话。发生后台、锁屏或音频上下文中断会停止有效计数并记录原因；恢复时重新学习背景，不计算跨中断步频。中断后的音频定位为估计，需人工核对。设备时钟不属于可信时间认证，日志不自动取得法律证据资格。

Safari 必须同时支持 AudioWorklet、MediaRecorder 和 IndexedDB；录音格式按实际支持探测。不支持时不会启动记录。存储失败会结束会话并保留已收到的内存音频，请保持页面打开并立即导出。页面关闭后只能恢复成功写入的分块，尾部可能缺失。不要依赖锁屏连续录音。

## 读数说明

- 频率单位为 Hz。
- 电平单位为 dBFS，是相对于数字满刻度的电平，并非经过声压校准的 dB SPL。
- 频谱结果会受到麦克风频响、自动增益、降噪处理、设备摆放和房间反射影响。
- 本工具适合定位和比较噪音频率，不替代经过校准的专业声级计或测量麦克风。

## 隐私

音频只在本机浏览器处理，不上传。实时频谱历史在刷新后消失；明确开始录音的完整音频分块、参数与事件日志保存在该站点的 IndexedDB，未导出会话不会自动删除。浏览器清理站点数据、无痕模式或系统存储回收可能使数据丢失，重要记录请及时导出。

## 技术结构

无需构建或第三方依赖。`index.html` 保留页面和原频谱逻辑，`impact-core.js` 实现滤波及事件检测，`impact-worklet.js` 负责音频线程短时能量，`record-logging.js` 管理会话和界面，`record-files.js` 负责 IndexedDB、ZIP 和报告。部署时必须一起提供这些运行文件与 `LICENSE`，不能只复制 HTML。
