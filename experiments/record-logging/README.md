# 低频记录实验页面

来源：`record-logging` 提交 `4980639`。五种分析共用记录功能，默认楼上噪声优化检测。独立目录包含运行所需文件及完整 MIT；相对于来源页面仅增加返回首页链接。

稳定版基线：`c4d77307f26b1a41e3aaf592d980cbcb4c748fb6`。稳定版首页仅增加实验入口，不加载实验脚本。此目录不包含开发方案、现场录音或导出物。

手机使用本站 HTTPS 地址，点击开始记录。五种模式均可记录、回听和导出。

## 撤销集成

本次集成是独立提交，提交标题为 `Expose isolated recording experiment through Pages entry`。对该提交执行 `git revert <集成提交SHA>` 并发布，即移除入口、实验目录及打包清单增项，不需要回滚整个 main。若后续修改相同区域，撤销时需处理冲突。

也可手动删除首页 BEGIN/END 标记之间的入口、整个 `experiments/record-logging` 目录及打包清单中的对应增项。录音保存在浏览器的站点存储中；删除入口不等于删除用户本机录音，撤销前请先导出重要记录。
